# 🛡️ 禁欲打卡

一个**零依赖**的禁欲/戒断打卡 Web 应用：记录破戒（时间、诱因、严重程度、备注），
并提供每周 / 每月统计、趋势图表与诱因分析。支持**云端同步**：多设备共享同一份数据。

- 纯前端单页应用 + 轻量同步 API
- 本地：数据保存在浏览器 localStorage，离线可用
- 云端：可选开启，访问码认证，多端同步

## ✨ 功能

| 模块 | 说明 |
|------|------|
| 🏠 状态 | 实时显示已坚持时长（精确到秒）、本周进度、快捷统计、个性化提醒 |
| ⚠️ 破戒记录 | 手动记录破戒：时间（支持补记）/ 诱因 / 严重程度 / 备注，可修改、可删除 |
| 📊 统计 | 本周/本月破戒数（含环比）、最长连续、平均间隔、近 12 周 & 近 6 月柱状图、诱因 Top、时段分布 |
| ☁️ 云同步 | 访问码认证，多设备同步同一份数据（自动同步 + 手动同步） |
| 📜 记录 | 历史记录列表，可编辑、可删除 |
| ⚙️ 设置 | 目标名称与开始日期、数据导出 / 导入（JSON 备份）、清空数据 |

## ☁️ 云端同步怎么用

1. 打开 **设置** 页 → **云端同步**
2. 点 **「生成新访问码」**，得到一个 8 位访问码（如 `K7D2-9F4M`），**请妥善保存**
3. 在其他设备（手机/电脑）打开同一网址，在云端同步里**输入这个访问码** → 连接并同步
4. 之后任何设备的记录变更都会**自动同步**；也可以随时点 **「立即同步」** 手动同步

> ⚠️ 访问码就是你的数据钥匙：知道访问码的人都能读写你的数据，请勿泄露。

### 同步原理（冲突处理）

- 每条记录带 `updatedAt` 时间戳，合并时**新版本覆盖旧版本**
- 删除记录时保留删除标记，同步后不会在其他设备"复活"
- 云端数据按访问码隔离存储，每账号一行

## 🚀 本地运行

### 方式一：直接打开

双击 `index.html`，用浏览器（Chrome / Edge 推荐）打开即可使用。

### 方式二：本地服务器预览

```bash
node server.js   # 然后访问 http://localhost:8765
```

## 💾 数据备份

- **导出**：设置页 →「导出数据」，下载 JSON 备份文件。
- **导入**：设置页 →「导入数据」，选择备份文件，覆盖当前数据。
- 建议定期导出备份，或更换设备后导入继续使用。

## 🔒 隐私说明

- 页面本身**不采集任何数据**，本地数据仅存于浏览器 localStorage。
- 启用云端同步后，数据会上传到云端数据库（仅凭访问码可访问）。
- 云端与本地备份文件请妥善保管，包含你的隐私记录。
